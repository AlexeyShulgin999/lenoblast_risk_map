# Карта экологических и транспортных рисков Ленинградской области

Интерактивная исследовательская карта на **OpenStreetMap / Leaflet** для предварительной оценки мест для покупки недвижимости.

**Адрес после включения GitHub Pages:** https://AlexeyShulgin999.github.io/lenoblast_risk_map/

## Как включить сайт

1. Откройте в этом репозитории **Settings → Pages**.
2. В **Build and deployment** выберите **Deploy from a branch**.
3. Укажите **main** и **/(root)**, нажмите **Save**.
4. После публикации откройте ссылку выше.

## Как обновлять

- `data.geojson` — редактируемая база объектов (координаты, категории, статусы, источники, степень точности).
- `index.html` — интерфейс карты. На GitHub Pages он при каждом открытии загружает свежий `data.geojson`; при локальном просмотре использует встроенную копию.
- При добавлении или редактировании объектов достаточно обновить **только `data.geojson`**. Адрес сайта и дизайн не меняются.
- ChatGPT с подключённым GitHub может вносить обновления в `data.geojson` по вашему запросу.

В файле `data.geojson` порядок координат для точек — `[долгота, широта]` (формат GeoJSON).

## Содержание

Первоначально внесено **23 объекта и схематических направления** (22 октября 2026). Есть КПО, полигоны, карьеры, промзоны, аэродромы, проектные дороги, отмеченный участок 47:07:0157001:973; фильтры, список объектов, ссылки на источники, проверка расстояний от введённой точки и возможность запросить контуры промышленности из OSM (Overpass).

## Ограничения достоверности

**Это не официальная градостроительная карта и не подтверждение безопасности участка.**

- Проектные **КАД‑2, ВСМ, ШМСД и обход Всеволожска** пока приведены **списком**, без линий на карте: прежние схематические линии могли создавать ложное представление о точной трассировке. Линии появятся только после загрузки проверенной геометрии из официальных документов.
- Некоторые точки соответствуют району или населённому пункту, а не точному положению объекта; степень точности указана в карточке.
- Круги 10 км — только ориентиры для проверки, не официальные СЗЗ.
- Контуры OSM — данные сообщества, могут быть неполными и не иметь юридической силы.
- Перед авансом проверяйте актуальные генпланы, ПЗЗ, ППТ, ЗОУИТ, ЕГРН и ограничения по кадастровому номеру.
